# SPH + particle building demo

Это отдельная экспериментальная реализация, не заменяющая основной проект.

Идея: и вода, и объект удара представлены частицами. Вода считается простым
SPH-методом, а вместо машины взято массивное "здание" из частиц, соединённых
упругими связями. Такой объект легче деформировать и визуализировать, чем
тонкостенный кузов.

## Что моделируется

- вода: SPH-частицы;
- здание: частицы + пружины между соседями;
- земля: плоскость `z = 0`;
- результат: файлы `.vtk`, которые открываются в ParaView.

## Сборка

```bash
cmake -S sph_building_demo -B sph_building_demo/build
cmake --build sph_building_demo/build -j2
```

## Запуск

```bash
./sph_building_demo/build/sph_building_demo
```

Результаты появятся в:

```text
sph_building_demo/results/latest_run
```

В ParaView можно открыть серии:

- `water_0000.vtk`, `water_0001.vtk`, ...
- `building_0000.vtk`, `building_0001.vtk`, ...

Для воды удобно включить `Point Gaussian` или `Glyph`, чтобы частицы были
крупнее и лучше видны.

## Важное замечание

Здание здесь не является настоящим solid SPH в строгом смысле. Это более простая
particle-based модель: частицы здания связаны пружинами. Для учебной визуализации
это понятнее, но физически менее строго, чем расчёт деформации через FEM.
